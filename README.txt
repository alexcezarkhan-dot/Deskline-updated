DeskTerminal Trading Journal - upload instructions

1. SUPABASE (do this first)
   Open Supabase > SQL Editor > paste the contents of supabase-trades.sql > Run.
   (supabase-trades.sql is NOT uploaded to GitHub; it only runs in Supabase.)

2. GITHUB
   Upload every .html file in this folder to your repo, keeping the same
   folders (journal.html goes in the repo root next to index.html).
   Overwrite the existing files when asked. Then commit.
   Netlify deploys automatically.

3. TEST
   Open /journal.html, sign in, add a trade, refresh. It should still be there.
